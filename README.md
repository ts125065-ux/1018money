# 我的錢，我的選擇

國小高年級「金融教育 × 綜合活動 × SEL」互動教學網站。

純 HTML、CSS、JavaScript，不需安裝套件、資料庫、API 金鑰或編譯工具。可直接部署到 GitHub Pages，也能解壓縮後使用瀏覽器開啟 index.html。

## 用 GitHub Pages 發布

1. 登入 GitHub，建立新儲存庫，建議名稱：`money-choices-sel`。若希望學生直接透過網址進入，可使用 Public 公開儲存庫，並避免上傳任何學生資料或未授權教材。
2. 將本壓縮檔解壓縮。於儲存庫選擇 **Add file → Upload files**，上傳解壓縮後的檔案，不要只上傳 ZIP。`index.html`、`style.css`、`app.js` 要位於同一層，且 `index.html` 必須直接出現在儲存庫最外層。
3. 按 **Commit changes** 儲存檔案。
4. 開啟儲存庫的 **Settings → Pages**。
5. 在 **Build and deployment** 區域，將 **Source** 設為 **Deploy from a branch**。
6. 在 **Branch** 選擇 `main`、資料夾選擇 `/(root)`，再按 **Save**。若分支名稱不同，選擇實際存放檔案的分支。
7. 等待發布完成，回到 Pages 設定頁取得實際網址。一般專案網址格式為 `https://你的帳號.github.io/money-choices-sel/`，此為格式範例，請以 GitHub 顯示的網址為準。
8. 在另一部裝置開啟網址，確認學生可以進入，再分享給班級。

網頁版上傳若沒有包含 `.nojekyll`，本專案沒有特殊目錄或需被 Jekyll 處理的內容，仍可使用；透過 Git 上傳時可保留此空白檔案。

## 檔案用途

| 檔案 | 用途 |
| --- | --- |
| `index.html` | 網站入口與基本頁面結構 |
| `style.css` | 版面、手機平板適配與列印樣式 |
| `app.js` | 三個任務、回饋、預算計算與學習紀錄 |
| `.nojekyll` | 讓 GitHub Pages 直接提供靜態內容 |
| `.gitignore` | 避免常見系統暫存檔進入版本管理 |
| `README.md` | GitHub 發布與網站使用說明 |

本資料包不需要原先的 Sites 帳號、部署識別碼或任何秘密憑證。網站以相對路徑載入資源，可部署於 GitHub 專案子路徑；任務切換使用網址雜湊，不需伺服器路由設定。

## 學生操作

1. 首頁輸入暱稱或座號代碼，避免輸入真實姓名。
2. **第一站 心情與購物**：完成6個生活情境，選擇做法，寫下感受與理由。按「儲存這次思考」或完成後按下一題。
3. **第二站 朋友與選擇**：完成3組對話，選擇回應後，寫出自己的說法及延伸思考。
4. **第三站 預算實驗室**：分配500元虛擬預算，寫下目標和理由。原始配置總額須剛好500元；遇到80元新增必要支出後，其餘配置總額須為420元，含修補費合計500元。
5. 進入「我的學習紀錄」，填寫生活行動反思，再按「列印／另存 PDF」。在瀏覽器的列印視窗選擇儲存為PDF，或直接列印。

需要、想要與不同選擇都有討論空間。回饋用於引導思考，不以存最多錢、捐款最多或最快作答來評分。

## 教師使用

網站內附「教師指南」，提供每節40分鐘、共3節的四學安排、SEL與綜合活動對應，以及學習證據蒐集方式。

- 第一節：消費情緒、自我覺察與自我管理。
- 第二節：朋友邀約、借貸、人際溝通與理解差異。
- 第三節：預算配置、突發事件、同儕互評與負責任的決定。

學生可以各自使用裝置；若共用裝置，請先列印一位學生的紀錄，再清除紀錄讓下一位使用。教師可蒐集PDF及課堂觀察記錄作為實際施教成果，網站未預填學生成效。

## 紀錄與限制

- 作答記錄保存在同一瀏覽器的 `localStorage`，沒有教師端、登入系統、雲端作答資料庫或自動收件功能。
- 無法跨裝置同步；清除瀏覽資料、使用無痕模式或更換瀏覽器，可能讓紀錄消失。搬到 GitHub Pages 後，原先 Sites 網址的作答紀錄不會自動搬過去。
- 消費與對話題需按儲存或下一題才會保存。預算挑戰需完成兩階段並按最後儲存；未完成的預算草稿不會在重新整理後保留。
- 本機直接開啟時，瀏覽器對儲存功能的支援可能不同。正式授課建議使用 GitHub Pages 網址，並在課前測試裝置與列印功能。
- 發布網站只會發布程式及課程文字，不會自動上傳學生在本機輸入的答案。請勿把學生作答檔、姓名或課堂照片直接放入公開儲存庫。

## 修改內容

- 修改題目、選項與回饋：編輯 `app.js` 的 `cases` 與 `talks` 資料。
- 修改配色、字體與版面：編輯 `style.css`。
- 修改網站標題與描述：編輯 `index.html`。
- 儲存修改並提交後，GitHub Pages 會依設定重新發布。

## 設計依據

本網站依使用者提供的《金融基礎教育學習架構》（107年修正）、十二年國民基本教育綜合活動領域課綱、教育部114–118年SEL中長程計畫，以及以學生為中心的四學教學模式進行課程轉化。原始PDF未包含在這個公開發布包中。

綜合活動主要學習表現為2c-III-1及2b-III-1。網站中的觀察規準為本課自訂，未以國中IV學習階段評量標準當作高年級規準。
